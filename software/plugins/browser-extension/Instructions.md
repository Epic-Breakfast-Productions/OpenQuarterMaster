# To use this browser extension:

0. Have the browser-extension-hello-world folder saved to your computer 
(software\plugins\browser-extension\browser-extension-hello-world)
1. Go to chrome://extensions
2. Toggle on Developer mode
3. Click "Load Unpacked" and select the folder

--------------------------------------------------------------

When you click the extensions icon on your browser toolbar, you should now be able to open this extension!
